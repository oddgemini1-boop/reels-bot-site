Privacy Policy / 개인정보처리방침

Last updated: 2026-10-12

English

reels-bot is a personal, non-commercial tool used only by its owner. It runs on the owner's own computer.

  • Data accessed: With the owner's permission, reels-bot uses Google OAuth to upload videos to the owner's YouTube channel (scope youtube.upload) and to read the channel name for confirmation (scope youtube.readonly). It also uses the Instagram API to publish the owner's videos to the owner's Instagram account.
  • Storage: Access tokens are stored only in local files on the owner's computer. No data is sent to any server operated by reels-bot; there is no such server.
  • Sharing: No data is sold, shared with third parties, or used for advertising. Data is sent only to Google/YouTube and Meta/Instagram to perform the uploads the owner requests.
  • Revoking access: Access can be revoked at any time at Google Account permissions and in Instagram settings, and by deleting the local token files.
  • reels-bot's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

한국어

  • reels-bot은 운영자 본인만 사용하는 비상업용 개인 도구이며, 운영자의 컴퓨터에서만 실행됩니다.
  • 운영자의 허락을 받아 Google OAuth로 운영자의 유튜브 채널에 영상을 올리고(youtube.upload), 확인용으로 채널 이름을 읽습니다(youtube.readonly). 인스타그램 API로 운영자의 인스타그램 계정에 영상을 게시합니다.
  • 토큰은 운영자 컴퓨터의 파일에만 저장되며, reels-bot이 운영하는 서버는 없습니다.
  • 데이터를 판매하거나 제3자와 공유하거나 광고에 쓰지 않습니다. 업로드를 위해 Google/YouTube와 Meta/Instagram에만 전송됩니다.
  • 언제든 Google 계정 권한과 인스타그램 설정에서 접근을 해제하고 토큰 파일을 지울 수 있습니다.
